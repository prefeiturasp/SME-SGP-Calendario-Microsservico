SME-SGP-Calendario-Microsservico
================================

Documentação de domínio do microsserviço do Calendário Escolar da Rede
Municipal de Ensino. O serviço é extraído do monólito NOVO-SGP pelo
padrão Strangler Fig e passa a ser o dono dos dados de calendário.

Esta documentação registra regras de negócio, decisões de arquitetura e
o mapeamento com o legado. A documentação da API HTTP fica no Swagger,
em ``/api/v1/docs/``.
